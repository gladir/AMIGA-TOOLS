# AMIGA-TOOLS
Ensemble d'outils pour Amiga écrit en Pascal (Turbo Pascal ou Free Pascal).

<h2>Liste des fichiers</h2>

Voici la liste des différents fichiers proposés dans AMIGA-TOOLS :

<table>
		<tr>
			<th>Nom</th>
			<th>Description</th>	
		</tr>
		<tr>
			<td><b>UNDISKAM.PAS</b></td>
			<td>Cette commande permet d'extraire tous les fichiers contenus dans une image disque de format .ADF de l'Amiga (systèmes OFS et FFS).</td>
		</tr>
</table>  

<h2>Compilation</h2>
	
Les fichiers Pascal n'ont aucune dépendances, il suffit de télécharger le fichier désiré et de le compiler avec Free Pascal avec la syntaxe de commande  :

<pre><b>fpc</b> <i>LEFICHIER.PAS</i></pre>
	
Sinon, vous pouvez également le compiler avec le Turbo Pascal à l'aide de la syntaxe de commande suivante :	

<pre><b>tpc</b> <i>LEFICHIER.PAS</i></pre>
	
Par exemple, si vous voulez compiler DIRST.PAS, vous devrez tapez la commande suivante :

<pre><b>fpc</b> UNDISKAM.PAS</pre>
